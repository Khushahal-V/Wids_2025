## Q1. Single-Node LangGraph with Chat History

### Objective
Build a **LangGraph application with a single Hugging Face LLM node** that:
- Answers user queries
- Maintains **chat history in graph state**
- Is tested with multiple queries from different domains

---

### Approach

- A custom **graph state (`GraphState`)** is defined using `TypedDict`
- The state stores a sequence of `HumanMessage` and `AIMessage` objects
- A single LangGraph node (`llm_node`) is created that:
  - Reads the entire message history from state
  - Formats messages into Hugging Face chat format
  - Calls a Hugging Face hosted LLM using `InferenceClient`
  - Appends the model’s response back into state

---

### Model Used
- **Model:** `meta-llama/Llama-3.2-3B-Instruct`
- **Provider:** Hugging Face Inference API
- **Temperature:** `0.7`
- **Max tokens:** `512`

---

### Graph Design

- Entry point: `llm`
- Single node graph
- The graph terminates immediately after the LLM responds

User Input → LLM Node → END


---

### Testing

The graph is tested using **three different user queries**:
1. Coding: *“Explain Python decorators”*
2. Mathematics: *“What is the derivative of x²?”*
3. General Knowledge: *“Who discovered gravity?”*

The same state object is reused across queries to verify that
**conversation history is preserved**.

---

### Key Concepts Demonstrated

- LangGraph `StateGraph` construction
- State persistence using message accumulation
- Hugging Face LLM integration via `InferenceClient`
- Multi-turn conversational behavior with a single node

## Q2. Two-Agent LangGraph: Question Analyzer + Answer Generator

### Objective
Build a LangGraph workflow with **two Hugging Face–backed agents**:
1. **Question Analyzer** – rewrites and clarifies the user’s question
2. **Answer Generator** – produces the final response based on the clarified question

The agents communicate through shared graph state.

---

### Approach

- A structured graph state (`GraphState`) is defined containing:
  - `user_question`
  - `clarified_question`
  - `final_answer`
- A Hugging Face text-to-text generation model is used for both agents
- The first agent reformulates the input question for clarity
- The second agent generates a concise and clear answer using the rewritten question

---

### Model Used
- **Model:** `google/flan-t5-base`
- **Pipeline:** `text2text-generation`
- **Provider:** Hugging Face Transformers

---

### Graph Design

User Question


↓
Question Analyzer


↓
Answer Generator


↓
END


---

### Implementation Details

- **Question Analyzer Node**
  - Takes the original user question
  - Rewrites and clarifies it using an instruction-based prompt
  - Stores the result in `clarified_question`

- **Answer Generator Node**
  - Reads the clarified question from state
  - Generates a final answer
  - Stores the output in `final_answer`

---

### Example Test Case

- **Input Question:**  
  *“What is backpropagation in neural networks?”*

- The graph outputs:
  - A clarified version of the question
  - A final concise explanation generated by the second agent

---

### Key Concepts Demonstrated

- Multi-node LangGraph workflows
- Agent-to-agent communication via shared state
- Task decomposition into reasoning and answering stages
- Use of instruction-following transformer models

## Q3. Router-Based LangGraph with Specialized Agents

### Objective
Implement a **router-based LangGraph** that:
- Reads the user query
- Decides which specialized agent should handle it
- Routes the query accordingly
- Ends execution after the selected agent responds

---

### Agents

- **Python Agent**
  - Handles programming-related questions
- **General Agent**
  - Handles general knowledge questions

---

### Model Used
- **Model:** `google/flan-t5-base`
- **Pipeline:** `text2text-generation`

---

### Routing Logic

- The router node examines the user message
- If Python-related keywords are detected
  (`python`, `function`, `list`, `class`, etc.),
  the query is routed to the **Python Agent**
- Otherwise, it is routed to the **General Agent**

---

### Graph Design

User Message
↓
Router
/
/
Python General
Agent Agent
↓ ↓
END END


---

### Implementation Details

- **Router Node**
  - Performs keyword-based intent detection
  - Sets the `route` field in graph state

- **Python Agent**
  - Uses a programming-focused prompt
  - Generates clear, structured explanations

- **General Agent**
  - Uses a general-purpose prompt
  - Answers non-programming questions

- Conditional edges determine which agent is executed

---

### Example Test Case

- **Input:**  
  *“What is photosynthesis?”*
- **Routing Decision:**  
  → General Agent
- **Output:**  
  A clear explanation generated by the selected agent

---

### Key Concepts Demonstrated

- Conditional routing in LangGraph
- Agent specialization
- Decision-making nodes
- Modular and extensible graph design
